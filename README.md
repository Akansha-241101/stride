# STRIDE Sneaker Store UI

## Overview
Responsive sneaker-store landing page UI practice project recreating a reference design. Static UI only.

## Features
- Navbar, Hero, Benefits strip, Featured Collection, Brand Story
- Responsive (mobile, tablet, desktop)
- Visual UI only - no functionality

## Tech Stack
- Vite
- React 19
- Tailwind CSS v4
- lucide-react

## Setup with Bun
```bash
bun install
bun run dev
```

## Development
```bash
bun run build
bun run preview
bun run lint
```

## Project Structure
- src/components/ - UI components
- src/data/products.js - static data
- public/images/ - assets
- docs/ - project documentation

## Notes
No backend, auth, cart, or business logic.
