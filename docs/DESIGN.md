# Design System - STRIDE

## Colors
- Main background: #FFFFFF
- Main text: #183C2F (dark forest green)
- Featured section: #829C8B (muted sage green)
- Card surface: #F3F3F1 (very light gray)
- Accent lime: #D6F65A
- Accent pink: #F29BC9
- Borders: subtle light gray

## Typography
- Headings: bold geometric sans-serif
- Body/Nav: Inter (400/500/600)

## Assets Mapping
- Hero sneaker: hero-sneaker-removebg-preview.png
- Everyday Essentials: everyday-sneaker-removebg-preview.png
- Performance Sneakers: performance-sneaker-removebg-preview.png

## Breakpoints (Tailwind)
- sm: 640px, md: 768px, lg: 1024px, xl: 1280px, 2xl: 1536px

## Navbar
- Compact layout, no outer border.
- Left: STRIDE logo (bold, dark green). Center: nav links pill (#F3F3F1). Right: Search + Cart icons, "Cart (2)".
- Font: Inter.

## Hero
- Left: eyebrow, bold uppercase heading, paragraph, 2 CTA buttons.
- Right: large "STRIDE" watermark top-right, hero sneaker overlapping, product card bottom-right.
- No decorative squares.

## Layout Notes
- Benefits: 4 items evenly spaced, divider.
- Featured: sage green rounded section, 3 cards.
- Brand Story: 3-part layout.
- Prevent horizontal overflow.
